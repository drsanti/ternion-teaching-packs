# เสียงและไมโครโฟน — คู่มือครู

บทเรียน 3 บทเรื่องเสียง วัดสด ๆ ด้วยไมโครโฟนของแล็ปท็อป ใช้เฉพาะตัวเลข (ความดัง ระดับเสียง จังหวะ) ไม่มีการบันทึกหรือส่งเสียงไปที่ใด

## ก่อนสอน

- เพิ่มบทเรียนทั้ง 3 บทจากคลังบทเรียน (แต่ละบทเป็นสำเนาของคุณเอง)
- เปิดบทเรียน กด Present แล้วกด **L** เพื่อเชื่อมต่อไมโครโฟน และกดอนุญาตเมื่อเบราว์เซอร์ถาม ลองสไลด์แบบสดหนึ่งครั้ง
- กด Run ในแบบฝึกหัดหนึ่งข้อ เพื่อให้ดาวน์โหลด Python runtime ไว้ในเครื่อง

## บทเรียน

1. **ความดัง** (35 นาที) — เสียงคือการสั่น ความดังของเสียง และความเร็วที่เสียงเดินทาง
2. **ระดับเสียงและความถี่** (40 นาที) — เสียงสูงและต่ำ เฮิรตซ์ ความยาวคลื่น และอ็อกเทฟ
3. **จังหวะและตัวนับเสียงปรบมือ** (35 นาที) — การตรวจจับจังหวะ การนับเสียงปรบมือจากข้อมูล และความเร็วจังหวะเป็นครั้งต่อนาที

แต่ละบทมีแบบฝึกหัด Python ที่ตรวจอัตโนมัติ 2 ข้อ พร้อมสไลด์เฉลยสำหรับครูเท่านั้น และมีการตรวจที่ซ่อนไว้บทละหนึ่งข้อซึ่งตรวจบนเครื่องของครู แบบทดสอบต้องเริ่มชั้นเรียนก่อน (Present ▾ → Start a class)

## เคล็ดลับ

- ห้องที่เงียบทำให้สไลด์แบบสดชัดขึ้น ไมโครโฟนในแล็ปท็อปก็เพียงพอ
- ระดับเสียงอ่านได้ดีที่สุดจากการฮัมหรือร้องโน้ตเดียวที่คงที่
