# Python basics — teacher guide

Three lessons of about 40 minutes: values and printing, decisions and loops, functions. No equipment: every exercise is a Python cell that runs on the slide, in the browser.

## Before the course

- Open each lesson once and press Run on an exercise, so the Python runtime is downloaded on your computer.
- Decide whether students work on their own devices (start a class: Present → Run a class) or watch the main screen.

## Grading

- Each exercise is checked after every run; the result shows under the code.
- Checks marked hidden are graded on your computer only: students see "not graded" until the class is running.
- Solution slides are teacher-only: in a class, students' devices show "Look at the main screen".

## Common mistakes

- Forgetting the quotes around text, or putting maths inside quotes (lesson 1).
- Indentation: the body of if and for must be indented by the same amount (lesson 2).
- print instead of return inside a function (lesson 3).
