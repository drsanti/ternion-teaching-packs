# พื้นฐานระบบสมองกลฝังตัวกับบอร์ด ws28p — คู่มือครู

บทเรียน 3 บท บทละประมาณ 40 นาที: รับรู้–คิด–ลงมือทำ ปุ่มและการเด้ง สัญญาณและการสุ่มตัวอย่าง ถ้ามีบอร์ด robotos ws28p และสาย USB ต่อคนหรือต่อคู่จะดีที่สุด ถ้าไม่มี ทุกบทเรียนใช้บอร์ดจำลองได้และทุกการตรวจยังผ่าน

## ก่อนสอน

- การเชื่อมต่อบอร์ดจริงต้องใช้ Chrome หรือ Edge (Web Serial)
- เปิดแต่ละบทเรียนหนึ่งครั้งและกด Run ในแบบฝึกหัด เพื่อให้ดาวน์โหลด Python runtime

## การตรวจบอร์ด

- สไลด์ที่สองของแต่ละบทเชื่อมต่อบอร์ดสำหรับทั้งบท
- การตรวจจะทำงานตามจำนวนวินาทีหลังกด Start และรายงานแต่ละเงื่อนไข บอร์ดจำลองผ่านทั้งหมด (ปุ่ม PWR กดทุก 4 วินาที การเอียงเปลี่ยนช้า ๆ)

## การตรวจแบบฝึกหัด

- แบบฝึกหัดจะถูกตรวจหลังการรันทุกครั้ง การตรวจที่ซ่อนไว้จะตรวจบนเครื่องของครูระหว่างชั้นเรียน สไลด์เฉลยเป็นของครูเท่านั้น

## ข้อผิดพลาดที่พบบ่อย

- ลืมลบ lo ตอนแปลงค่า (แบบฝึกหัด 1)
- นับทุกค่า 1 แทนที่จะนับการเปลี่ยน 0 → 1 (แบบฝึกหัด 3)
- สไลซ์เกินหรือขาดไปหนึ่งค่า (แบบฝึกหัด 5)
