# เซนเซอร์กับบอร์ด ws28p — คู่มือครู

บทเรียน 3 บทกับบอร์ด robotos ws28p (ESP32-S3): ปุ่ม เซนเซอร์การเคลื่อนไหว และเวลาตอบสนอง

## อุปกรณ์

- บอร์ด ws28p และสาย USB สำหรับข้อมูล 1 ชุดต่อผู้เรียน 2 คน และแล็ปท็อปที่มี Chrome หรือ Edge
- **ไม่มีบอร์ด?** ทุกบทเรียนใช้บอร์ดจำลองได้: ที่สไลด์ "เชื่อมต่อบอร์ด" กด **No board here? Use a simulated robotos board** ใต้การ์ด (เฉพาะผู้นำเสนอเท่านั้นที่เห็น) เวลาตอบสนองมีความหมายเฉพาะเมื่อใช้บอร์ดจริง

## บทเรียน

1. **รู้จักบอร์ด** (30 นาที) — บนบอร์ด ws28p มีอะไรบ้าง การเชื่อมต่อ และปุ่มทั้งสอง
2. **การเอียงและแรงโน้มถ่วง** (40 นาที) — เซนเซอร์วัดความเร่ง สามแกน และการอ่านการเอียงจากแรงโน้มถ่วง
3. **เวลาตอบสนอง** (35 นาที) — วัดว่ากดปุ่มได้เร็วแค่ไหน แล้วเปรียบเทียบและพัฒนา

แบบทดสอบและโพลต้องเริ่มชั้นเรียนก่อน (นำเสนอ → Start a class) บันทึกผู้บรรยายในทุกสไลด์บอกว่าต้องทำและพูดอะไร
