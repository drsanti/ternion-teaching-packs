# พื้นฐาน Python — คู่มือครู

บทเรียน 3 บท บทละประมาณ 40 นาที: ค่าและการพิมพ์ การตัดสินใจและลูป ฟังก์ชัน ไม่ต้องใช้อุปกรณ์ ทุกแบบฝึกหัดเป็นเซลล์ Python ที่รันบนสไลด์ในเบราว์เซอร์

## ก่อนสอน

- เปิดแต่ละบทเรียนหนึ่งครั้งและกด Run ในแบบฝึกหัด เพื่อให้ดาวน์โหลด Python runtime ไว้ในเครื่องของคุณ
- ตัดสินใจว่าผู้เรียนจะทำบนอุปกรณ์ของตัวเอง (เริ่มชั้นเรียน: นำเสนอ → Run a class) หรือดูจอหลัก

## การตรวจ

- แบบฝึกหัดจะถูกตรวจหลังการรันทุกครั้ง ผลแสดงใต้โค้ด
- การตรวจที่ซ่อนไว้จะตรวจบนเครื่องของครูเท่านั้น ผู้เรียนเห็น "ยังไม่ตรวจ" จนกว่าชั้นเรียนจะเริ่ม
- สไลด์เฉลยเป็นของครูเท่านั้น ในชั้นเรียน อุปกรณ์ของผู้เรียนจะแสดง "ดูที่จอหลัก"

## ข้อผิดพลาดที่พบบ่อย

- ลืมเครื่องหมายคำพูดรอบข้อความ หรือใส่การคำนวณไว้ในเครื่องหมายคำพูด (บทที่ 1)
- การเยื้อง: ส่วนใน if และ for ต้องเยื้องเท่ากัน (บทที่ 2)
- ใช้ print แทน return ในฟังก์ชัน (บทที่ 3)
